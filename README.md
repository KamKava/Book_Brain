# Book Brain

Personal library management and reading analytics application.

## Current Status

Early development — database foundation being implemented.

## What Book Brain Will Do

- Catalogue books
- Track owned books and TBR
- Track reading history
- Track reading sessions
- Analyse reading habits
- Provide personalised recommendations
- Integrate external book metadata
- Eventually provide an AI librarian
